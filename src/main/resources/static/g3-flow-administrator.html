Asignación de un preventivo

Recorre el flujo administrativo: identifica al usuario, confirma su perfil, selecciona un preventivo pendiente y le asigna un inspector habilitado.

Paso 1Identificación
Paso 2Perfil autenticado
Paso 3Preventivos pendientes
Paso 4Asignar inspector

1. Identificación

Inicia sesión con una cuenta de administrador.

La página obtiene un JWT con POST /api/auth/login y solo lo conserva durante esta sesión del navegador.

2. Perfil autenticado

Se comprueba la identidad y el rol a partir del token recibido.

GET/api/users/me

4. Asignar inspector

Selecciona un inspector habilitado y confirma la asignación.

GET/api/users/by-role?role=ROLE_INSPECTOR

3. Preventivos pendientes de asignar

Solo se muestran ejecuciones en estado PENDING. Selecciona una para continuar el flujo.

GET/api/preventives/by-status?status=PENDING
Pendiente de identificaciónInicia sesión como administrador para cargar los preventivos disponibles.
